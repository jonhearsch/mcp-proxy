setup_signal_handlers() — currently registers only SIGINT:
  signal.signal(signal.SIGINT, signal_handler)   # Ctrl+C

_monitor_for_reload() — current fragile implementation:
  def _monitor_for_reload(self):
      while not self.shutdown_event.is_set():
          if self.reload_event.wait(timeout=0.5):
              logger.info("Config reload detected, requesting graceful restart...")
              self.restart_event.set()
              # FRAGILE: spawns extra thread to send SIGINT
              def shutdown():
                  os.kill(os.getpid(), signal.SIGINT)
              threading.Thread(target=shutdown, daemon=True).start()
              break

  Fixed version removes the Thread wrapper entirely:
      self.restart_event.set()
      os.kill(os.getpid(), signal.SIGTERM)
      break

  With SIGTERM now registered, the signal_handler sets shutdown_event.
  run_with_restart() then checks restart_event (set before signal) → reload path.

  The ordering guarantee: restart_event.set() BEFORE os.kill() ensures run_with_restart()
  sees restart_event=True when it wakes up after the signal causes proxy.run() to return.
