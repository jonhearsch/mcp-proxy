    configure_logging(log_level_str: str = "INFO", per_logger_str: str = "") -> None:
      This replaces setup_logging(). It must:
      1. Build shared_processors list: structlog.stdlib.add_logger_name, structlog.stdlib.add_log_level, structlog.stdlib.PositionalArgumentsFormatter, structlog.processors.TimeStamper(fmt="iso"), structlog.processors.StackInfoRenderer, structlog.processors.format_exc_info, structlog.processors.UnicodeDecoder.
      2. Call structlog.configure() with processors = shared_processors + [structlog.stdlib.ProcessorFormatter.wrap_for_formatter], wrapper_class=structlog.stdlib.BoundLogger, context_class=dict, logger_factory=structlog.stdlib.LoggerFactory(), cache_logger_on_first_use=True.
      3. Create a structlog.stdlib.ProcessorFormatter with processor=structlog.processors.JSONRenderer() and foreign_pre_chain=shared_processors.
      4. Set up a single StreamHandler(sys.stdout) with this formatter on the root logger. Set root logger level from log_level_str (using getattr(logging, log_level_str.upper(), logging.INFO)).
      5. Apply per_logger_str overrides: split on "," → each "name:LEVEL" → logging.getLogger(name).setLevel(level). Same logic as the existing MCP_LOG_LEVELS handling in setup_logging().
      6. Set logging.getLogger("fastmcp").setLevel(logging.INFO) and logging.getLogger("httpx").setLevel(logging.INFO) after the root handler is configured (same as current setup_logging() lines 147–151).

    get_logger(name: str = None) -> structlog.stdlib.BoundLogger:
      Returns structlog.get_logger(name) — a thin wrapper so callers do `from mcp_proxy.logging import get_logger` instead of importing structlog directly.

    Module-level imports needed: sys, logging, structlog.
